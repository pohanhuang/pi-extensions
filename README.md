# pi-extensions

Personal [pi](https://github.com/earendil-works/pi) extensions.

## Extensions

| Extension | Description |
|-----------|-------------|
| [usage-dashboard](./usage-dashboard/) | Token & cost dashboard with persistent session footer |
| [branch-workspace](./branch-workspace/) | Per-branch workspace with discuss / implement mode guard |
| [pi-ask-me](./pi-ask-me/) | `ask_me` tool that blocks the turn until you answer, reports blocked state to herdr |
